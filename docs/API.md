# HTTP API

Базовый адрес: `http://<сервер>:8770`. Все ответы — JSON (кроме файлов и интерфейса).
Интерактивная документация FastAPI: `/api/docs`.

Авторизация: заголовок `Authorization: Bearer <token>` (токен выдаётся при входе).

## Служебные

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| GET | `/api/health` | все | состояние сервера и версия |
| GET | `/api/public/info` | все | версия, название, требуется ли первичная настройка |
| GET | `/api/version` | все | версия и репозиторий обновлений |

## Первичная настройка и вход

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| POST | `/api/setup` | только до создания первого пользователя | создать администратора |
| POST | `/api/auth/login` | все | вход, возвращает токен, профиль и настройки |
| POST | `/api/auth/logout` | авторизованные | завершить сессию |
| GET | `/api/auth/me` | авторизованные | текущий пользователь и настройки |
| POST | `/api/auth/change-password` | авторизованные | сменить свой пароль |
| POST | `/api/auth/profile` | авторизованные | изменить ФИО, должность, e-mail |

Пример входа:

```bash
TOKEN=$(curl -s -X POST http://127.0.0.1:8770/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"Admin12345"}' | python3 -c 'import sys,json;print(json.load(sys.stdin)["token"])')
```

## Отчёты

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| GET | `/api/reports` | авторизованные | список отчётов (свои или все — по роли) |
| POST | `/api/reports` | авторизованные | создать отчёт (единственная операция записи) |
| GET | `/api/reports/{id}` | владелец, супервайзер, администратор | отчёт целиком |
| GET | `/api/reports/{id}/excel` | владелец, супервайзер, администратор | скачать заполненный бланк `.xlsx` |
| POST | `/api/reports/{id}/email` | владелец, супервайзер, администратор | отправить по почте |
| DELETE | `/api/reports/{id}` | **только администратор** | удалить отчёт |

Параметры списка: `scope` (`auto`/`mine`), `user_id`, `date_from`, `date_to`
(`YYYY-MM-DD`), `status` (`saved`/`sent`), `q`, `limit`, `offset`.

Тело запроса на создание:

```json
{
  "report_date": "2026-10-26",
  "person_name": "Кухаренко Юлия Владимировна",
  "person_position": "администратор отдела розничной сети",
  "purpose": "Командировочные расходы",
  "advances": [
    {"date": "2026-10-19", "amount": "99.00"}
  ],
  "expenses": [
    {"date": "22.10.2026", "document": "Проездной билет",
     "document_number": "ЖЕ2110185790394",
     "purpose": "проезд ЖД, Витебск-Минск", "amount": "28.45"}
  ]
}
```

Ответ содержит номер вида `АО-2026-0001`, итоги в копейках
(`received_cents`, `spent_cents`, `balance_cents`, `approved_cents`),
сумму прописью и строки отчёта. Ограничения: до 3 авансов и до 10 расходов,
суммы — до 99 999 999,99 руб.

Отправка по почте: `POST /api/reports/{id}/email` с телом
`{"to": "boss@example.com, hr@example.com", "comment": "Прошу утвердить"}`.
После успешной отправки статус становится `sent`, ошибки SMTP возвращаются
кодом `502` и сохраняются в поле `email_status`.

Изменение сохранённого отчёта недоступно: методов `PUT`/`PATCH` нет,
а в базе данных стоит триггер, отменяющий `UPDATE`.

## Пользователи

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| GET | `/api/users` | супервайзер, администратор | список пользователей |
| POST | `/api/users` | супервайзер, администратор | создать пользователя |
| PATCH | `/api/users/{id}` | администратор; супервайзер — только пароль обычному пользователю | изменить данные/роль/активность/пароль |
| DELETE | `/api/users/{id}` | **только администратор** | удалить пользователя без отчётов |

## Обновления

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| GET | `/api/update/check?force=1` | авторизованные | проверить релизы на GitHub |
| POST | `/api/update/install` | администратор (Windows-сборка) | скачать установщик, сделать копию базы и установить |

`update/check` возвращает `current_version`, `latest_version`, `update_available`,
`release_notes`, `assets` (файлы релиза по платформам), `download_url`,
`can_install`.

## Коды ошибок

| Код | Значение |
|---|---|
| 400 | неверный запрос (например, SMTP не настроен) |
| 401 | нет или истёк токен, неверный пароль |
| 403 | недостаточно прав, учётная запись заблокирована |
| 404 | объект не найден |
| 409 | конфликт (логин занят, у пользователя есть отчёты, программа уже настроена) |
| 422 | ошибка валидации, текст — в `detail` |
| 429 | слишком много неудачных попыток входа |
| 502 | ошибка отправки письма (SMTP) |
