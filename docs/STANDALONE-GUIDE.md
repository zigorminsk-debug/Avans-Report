# Автономная версия: заполнение, PDF и печать

Автономная программа для авансовых отчётов. Работает на одном компьютере,
**без сервера, без базы данных и без входа в систему**: любой, кто запустил
программу, сразу заполняет отчёт.

| | Серверная версия | Автономная версия |
|---|---|---|
| Где данные | на сервере, в базе | в папке отчётов на этом компьютере |
| Вход в систему | логин и пароль | нет |
| Кто видит отчёты | свои / все (по ролям) | все отчёты этого компьютера |
| Электронная почта | да | нет (PDF сохраняется и печатается) |
| Общая работа | несколько сотрудников | несколько окон на одном ПК |

Если отчёты ведёт несколько сотрудников с общим доступом и правами —
используйте серверную версию.

## Установка

**Windows.** Запустите `AvansStandalone-Setup-<версия>.exe`. Права
администратора не нужны: программа ставится в профиль пользователя
(`%LOCALAPPDATA%\Programs\AvansStandalone`). После установки на рабочем столе
и в меню «Пуск» появятся ярлыки «Авансовые отчёты (автономно)» и
«Каталог отчётов».

**Портативная версия.** Распакуйте `AvansStandalone-Portable-<версия>.zip`
в любую папку и запустите `AvansStandalone.exe`. Отчёты при этом всё равно
пишутся в `%LOCALAPPDATA%\AvansReportStandalone`, поэтому папку с программой
можно переносить на другой компьютер.

**Linux.** Распакуйте `AvansStandalone-Linux-x86_64-<версия>.tar.gz` и запустите

```bash
./AvansStandalone/AvansStandalone
```

## Как заполнить отчёт

1. Запустите программу. Откроется браузер с формой отчёта.
   Если браузер не открылся — перейдите по адресу, который показала программа
   (по умолчанию `http://127.0.0.1:8780/`).
2. Заполните шапку: дату отчёта, ФИО и должность подотчётного лица,
   назначение аванса.
3. Укажите полученные суммы (авансы): дату и сумму. Можно добавить несколько
   строк — «Итого получено» считается само.
4. Внесите расходы: дата, документ, номер, назначение, сумма (до 10 строк).
   Суммы можно вводить как `1250,50`, так и `1250.50`.
5. Итог и остаток (перерасход) пересчитываются сразу; сумма прописью
   подставляется автоматически.
6. Нажмите **«Сохранить отчёт»** — программа присвоит номер, запишет файл
   данных и создаст PDF.

Кнопка **«Предпросмотр»** открывает отчёт в том виде, в котором он будет
напечатан, — с подписями и блоком «УТВЕРЖДАЮ».

## Сохранение в PDF и печать

После сохранения в окне результата доступны:

- **«Скачать PDF»** — сохранить PDF в любую папку (имя вида
  `Авансовый отчёт АО-2026-0001 от 26.10.2026.pdf`);
- **«Печать»** — открывает системный диалог печати (в диалоге печати можно
  выбрать «Сохранить как PDF», если нужен файл);
- **«Открыть папку»** — показать папку с сохранёнными отчётами;
- **«Новый отчёт»** — начать следующий отчёт.

PDF всегда создаётся вместе с отчётом, поэтому его можно отправить по почте
или передать в бухгалтерию без повторного открытия программы.

## Несколько окон одновременно

Автономная версия поддерживает одновременную работу в нескольких окнах и
вкладках браузера:

- у каждого окна свой черновик — незаконченный отчёт одного окна не мешает
  другому (черновик сохраняется автоматически и не теряется при обновлении
  страницы);
- номера отчётов не повторяются: при одновременном сохранении из разных окон
  каждый отчёт получает свой номер;
- **повторный запуск программы не выдаёт ошибку «порт занят»**: второй запуск
  просто открывает новое окно к уже работающей программе
  (одна программа — сколько угодно окон).

Номер отчёта не используется повторно даже после удаления: следующий отчёт
получит следующий свободный номер.

## Нумерация

Номера имеют вид `АО-2026-0001`, где `2026` — год отчёта, `0001` — порядковый
номер в этом году. Нумерация ведётся автоматически по файлам в папке отчётов:
если перенести в неё готовые отчёты, программа продолжит нумерацию после
самого большого номера.

## Список отчётов

Раздел **«Отчёты»** показывает сохранённые отчёты: номер, дату, подотчётное
лицо, назначение, сумму и остаток. Для каждого отчёта доступны:

- **«PDF»** — открыть в браузере;
- **«Скачать»** — сохранить файл;
- **«Печать»** — печать;
- **«Удалить»** — удалить отчёт вместе с PDF (действие необратимо).

## Где хранятся отчёты

```
Windows: %LOCALAPPDATA%\AvansReportStandalone\reports\<сессия>\
Linux:   ~/.local/share/AvansReportStandalone/reports/<сессия>/
```

В папке лежат `АО-2026-0001.json` (данные отчёта) и `АО-2026-0001.pdf`.
Общие настройки (организация, подписи, назначения) хранятся рядом,
в `settings.json`.

Папку можно сменить переменной окружения `AVANS_STANDALONE_DATA_DIR`.
Ярлык «Каталог отчётов» в меню «Пуск» открывает текущую папку отчётов.

> Если папка отчётов недоступна для записи (например, программа запущена
> с носителя только для чтения), интерфейс предложит выбрать папку вручную
> и будет сохранять отчёты через браузер. Для этого нужен Chrome, Edge или
> Яндекс Браузер.

## Настройки

Раздел **«Настройки»** — организация, должности и ФИО руководителя и
бухгалтера, типовые назначения аванса, значения по умолчанию для подотчётного
лица, начальный номер отчёта. Настройки общие для всех окон.

## Резервная копия

Все отчёты — обычные файлы. Скопируйте папку отчётов (или весь каталог
`AvansReportStandalone`) на диск или в облако — это и есть резервная копия.
При обновлении и удалении программы отчёты не удаляются.

## Обновления

Кнопка **«Проверить обновления»** в левом нижнем углу интерфейса проверяет
страницу релизов на GitHub и, если доступна новая версия, предлагает скачать
установщик. Отчёты при обновлении сохраняются.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| Браузер не открылся | Откройте вручную адрес из окна программы (`http://127.0.0.1:8780/`) |
| «Порт занят» при запуске | Такого не бывает: второй запуск открывает уже работающую программу. Если окно не появилось, закройте все окна программы и запустите снова |
| Не сохраняется отчёт | Проверьте, что папка отчётов доступна для записи (ярлык «Каталог отчётов»), и что заполнены дата, ФИО, назначение и хотя бы одна строка расходов |
| Нужна печать без полей браузера | В предпросмотре нажмите «Печать»: поля уже учтены в макете A4 |
| Нужна совместная работа сотрудников | Используйте серверную версию: `docs/USER-GUIDE.md`, `docs/ADMIN-GUIDE.md` |

Журнал работы программы — `standalone.log` в папке отчётов.
