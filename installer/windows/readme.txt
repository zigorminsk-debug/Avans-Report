АВАНСОВЫЕ ОТЧЁТЫ
=================

Программа для заполнения, печати и отправки по электронной почте
авансовых отчётов. Клиент-серверная: сервер хранит базу данных,
сотрудники работают через браузер.

ПОСЛЕ УСТАНОВКИ
---------------
1. Программа запускается ярлыком «Авансовые отчёты».
2. При первом запуске откроется браузер и предложит создать
   учётную запись администратора.
3. Администратор настраивает организацию, подписи и SMTP-сервер
   в разделе «Настройки», затем создаёт пользователей.

РЕЖИМ СЕРВЕРА (работа нескольких сотрудников)
---------------------------------------------
1. Откройте файл config.json в каталоге данных
   (ярлык «Каталог данных» в меню «Пуск») и укажите:
       "host": "0.0.0.0",
       "port": 8770,
       "open_browser": false
2. Перезапустите программу. Сотрудники заходят по адресу
   http://IP-сервера:8770
3. Программа хранит данные в каталоге
   %APPDATA%\AvansReport — он не удаляется при обновлении.

ОБНОВЛЕНИЯ
----------
Кнопка «Проверить обновления» в левом нижнем углу интерфейса.
Перед установкой обновления автоматически создаётся резервная
копия базы данных.
